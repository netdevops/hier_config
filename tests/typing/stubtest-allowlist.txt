#
# `python scripts/build.py stubtest` checks `hier_config` recursively, including
# its native submodule. Native bindings have no exemptions: fix their metadata.
#
# Every entry below was audited and falls into one of these categories:
#
#   * pydantic models - `__init__` is synthesised at runtime with a
#     `self` parameter, while the stub uses pydantic's `__pydantic_self__`.
#   * PyO3 enums (`Platform`, `NegationStrategy`, `InterfaceDot1qMode`,
#     `InterfaceDuplex`, `NACHostMode`) - `__new__` takes `value`, and members
#     are native objects rather than the stub's Python enum members.
#   * Recursive/string-based `TypeAlias`es (`JsonValue`, `TextStyle`) differ
#     from the runtime representation of their annotations.
#   * Cached rule helpers expose wrapper signatures rather than their
#     underlying function signatures.
#
# Unused entries are an error, so this list stays honest: when a divergence is
# fixed the entry must be deleted. Do not add an entry to silence a genuine
# signature mismatch - fix the Rust binding or the stub instead.
